**This supersedes the incomplete v0.3.10 and v0.3.11 prereleases and is the urgent macOS
compatibility release for v0.3.9.** The bundled tmux in v0.3.9 could crash at startup on macOS 26
and older, leaving terminals unable to start for users without a separately installed tmux. The
rebuilt binary avoids newer-SDK-only functions, and the release build rejects unguarded weak
imports before they can ship.

This release also brings the account controls and reliability work added since v0.3.9: one
Settings surface for Claude and Codex accounts, account switching for running local and SSH
sessions, bulk session moves, configurable terminal parking, browser zoom, and fixes across agent
approvals, retained launches, hooks, context links, Windows update safety, editor layering, and tab
dragging.
