**The kanban board runs work now.** Drag an issue card into a dispatch column and it starts its own
agent run. A board comment that @mentions a session reaches that agent. An orchestrator's card shows
its team's progress instead of repeating facts you have already read, and agents can read the board's
GitHub lane themselves through new read-only `issues` and `prs` verbs. Orchestration state also
survives an app restart, `--after-pr` holds a node's launch until a pull request passes checks or
merges, and `--run-now` starts a queued node headless.

**⌘M is no longer Claude-only.** The chat view now works for Gemini — on the desktop and on the phone
over the relay — and for Codex, Copilot, opencode and Grok on SSH hosts. **Antigravity** joins the
agent list too.

**A team can be hosted from a Server Edition core**, joinable by invite code, so the machine holding
the session no longer has to be running the desktop app.

**Clicking a path in terminal output got serious.** Unicode, bracketed, spaced and bare paths and
`file://` URIs are all detected; a relative path resolves against the pane's live cwd; hovering shows
you the resolved path before you commit to the click; Shift+Cmd/Ctrl+click opens it with the OS app;
and "could not check" is no longer reported to you as "file not found". There is also a new
file-manager node — click selects, double-click opens, type-ahead finds.

Smaller, but you will meet them: a Figma-style Update button in the title bar, a minimize button on
the minimap, crisp WebGL text when zoomed in on a low-DPI display, and on a project switch the
terminals you can actually see attach first.
