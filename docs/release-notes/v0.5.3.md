**Quote text into the chat.** Select text in an agent's ⌘M conversation and an "Add to chat" button appears; copy text from an agent's terminal and the same offer shows in the corner for a few seconds. Either one puts the selection into that agent's message box as a markdown quote. Nothing is sent: you add your own words and press Enter. If the agent is waiting on a question or has left the terminal, nothing is typed and a notice says why.

**Read a Claude subagent as a conversation.** Click a subagent card on the canvas and it opens the subagent's own transcript in the same view ⌘M uses: its task at the top, its replies and tool calls, and any message you sent it. It updates while the subagent works. An opened card stays until you close it, instead of disappearing at the next turn. A selection in it can be quoted to the parent agent.

**Subagents are listed under their session.** The sessions sidebar shows one row per subagent under its agent, and a kanban card shows how many it has and how many are still working. A click takes you to the parent and opens that subagent's card.

**The upload notice on SSH terminals stays put.** While a dropped file copies to an SSH host, the "Uploading…" overlay now survives a project switch and its spinner actually spins. The kanban card shows the same overlay.

**Creating a card from the All projects board lands in the right project.** A new session started from another project's lane could be created against the canvas you were leaving. On Windows, a slow process lookup no longer drops the connection to the running sessions.
