**This supersedes the incomplete v0.3.10–v0.3.12 prereleases and is the urgent macOS compatibility
release for v0.3.9.** The bundled tmux in v0.3.9 could crash at startup on older macOS versions,
leaving terminals unable to start for users without a separately installed tmux. The rebuilt
binary uses private bundled compatibility functions instead of newer-SDK-only system symbols, and
the release build rejects unguarded weak imports before they can ship.

This release also includes the account controls and reliability improvements merged since v0.3.9,
including local and SSH account switching, configurable terminal parking, browser zoom, and fixes
across agent approvals, retained launches, hooks, context links, Windows updates, and editor UI.
