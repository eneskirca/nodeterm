**This is an urgent macOS compatibility release.** The bundled tmux in v0.3.9 could crash at
startup on macOS 26 and older, leaving every terminal without a separately installed tmux unable
to start. v0.3.10 rebuilds it without the unsupported `pipe2` dependency and adds a release-time
guard so a newer SDK cannot silently introduce the same class of failure again.

This release also brings the account controls added since v0.3.9: Claude and Codex accounts can be
managed from one Settings surface, running local and SSH sessions can switch accounts, and sessions
can be moved in bulk from the usage popover. Terminal parking is configurable, browser nodes can be
zoomed, and a broad reliability pass fixes agent approvals, retained launches, hooks, context links,
Windows update safety, editor layering, tab dragging, and several related edge cases.
